Chapter 01 · 第一部 地基

市场是什么
从撮合引擎说起

把 K 线图关掉。市场真正的样子，是一个不断接收订单、按价格优先时间优先排序、 逐笔撮合的有限状态机。理解这台机器怎么工作，你才会明白：为什么你的回测成交价是假的， 为什么大单会把价格推上去，以及为什么「流动性」是一个可以定价的东西。

阅读 26 分钟 难度 入门 代码 撮合引擎

几乎所有人第一次接触市场，看到的都是一张 K 线图：红红绿绿的柱子，上下影线， 均线交叉。这张图很有说服力，以至于人们忘了它是二手信息—— 它是把无数笔真实交易压缩、平滑、抽象之后的结果。就像你看一张城市交通热力图， 能看到拥堵，但看不到红绿灯的配时逻辑。

而交易的成本、成交的可能性、策略的容量，全部藏在那台被抽象掉的机器里。 这一章我们把它拆开。

1.1交易所的本质：一本不断变动的账

现代交易所的核心数据结构简单得令人失望：两个按价格排序的队列。 一个叫买盘（bid），一个叫卖盘（ask）。每个队列里是一张张限价单， 每张单子写着「我愿意用 X 价格买/卖 N 股」。

当一张新订单进来，撮合引擎做三件事：

  1. 能不能立刻成交？如果是买单，看卖盘最低价是否 ≤ 你的出价。能，就成交。
  2. 成交多少？取双方数量的较小值。剩余部分继续找下一个价位。
  3. 成交不完怎么办？如果是限价单，剩下的挂在买盘队列里排队；如果是市价单，剩下的撤销或按配置处理。

就这么多。没有魔法，没有庄家操盘的黑箱（至少在这一层没有）。 你看到的每一次价格跳动，都是这个循环的输出。

关键洞察

价格不是「算」出来的，是撮合出来的。这意味着价格的每一次变化， 都必须有一笔真实的成交作为代价。想让价格涨 1%，需要有足够多的买单把卖盘从当前价一路吃上去。 这个「吃」的过程有成本，成本的大小取决于盘口有多厚——这就是流动性。

1.2盘口：价格是分层的信息

如果你只能看一个数字，你看最新成交价。如果你能看十个数字，你看盘口（order book）。 盘口告诉你在每个价位上，有多少人愿意交易。

这张图里有三个信息，K 线永远不会告诉你：

  • 价差（spread）：100.50 − 100.40 = 0.10，约 10 个基点。这是你每次「往返交易」的固定门票。
  • 深度（depth）：卖盘前三档一共 12,300 股。你想买 20,000 股，就必然吃到 100.55 以上。
  • 不对称性：买盘比卖盘薄，说明当前买方更急，或者卖方更惜售。这是极短周期的信号来源之一。

1.3订单类型：你交给机器的指令

订单类型是你和市场对话的语法。用错了，策略逻辑再对也会亏在细节上。

常见错误

很多人用「止损单」来管理风险，却不知道止损单在流动性枯竭时是最危险的订单类型： 它会在最坏的时刻变成市价单，和所有其他止损单一起涌向同一个方向。 2020 年 3 月、2024 年 8 月日经暴跌，都出现过止损单连环触发的流动性真空。 止损应该是一个「决策」，不是一个「挂单」。

1.4价格不是连续函数

这是程序员最容易建立、也最容易被忽略的直觉。数学上我们习惯把价格写成 P(t)， 一条光滑曲线。但真实的价格是一个分段常数函数，只在成交发生的瞬间跳变。

更麻烦的是，成交在时间上极度不均匀。一只股票一天可能有几万笔成交， 但其中 80% 集中在开盘和收盘的几十分钟。中午可能几分钟都没有一笔。 如果你按「每 5 分钟一根 K 线」来建模，你实际上是在用时间采样去近似一个事件驱动的过程， 这中间的信息损失，就是很多策略「回测很好、实盘不灵」的原因之一。

1.5摩擦：四种你必然支付的成本

交易不是免费的。每一笔往返交易，你都在向系统支付四笔钱，它们决定了策略的「最低收益率门槛」。

价差成本

跨过买卖价差。流动性好的大盘股约 1–3 bps，小盘股可能 20–50 bps。日内策略的最大杀手。

佣金与税费

券商佣金、交易所规费、印花税（A 股卖出 0.05%）、过户费。低频策略里占比小，高频里致命。

冲击成本

你的订单改变了价格。下单量越大、越快，冲击越大。近似与 √(Q/V) 成正比。

时机风险

为了减少冲击而拆单慢买，价格却在你等待时跑掉了。执行的本质是在冲击与时机之间求最优。

把这几项加起来，一个日频换手 20% 的策略，年化成本可能高达 3–8%。这意味着： 如果你的毛 alpha 只有 5%，你其实在亏钱。第十章会专门讲怎么测量和优化它。

选择建议

如果你是新手，从流动性最好的宽基 ETF 或大盘股开始。不是因为它们容易赚， 而是因为它们的成本结构最干净、数据质量最好、被操纵的概率最低。 在一个干净的场地上练基本功，比在泥地里练摔跤有意义。

1.7谁在跟你做对手

这一点极其重要，却极少有人讲。你每一次成交，对面都有一个具体的人或机器。 知道对手是谁，你才知道自己凭什么赢。

  • 做市商：提供双边报价，赚价差。他们最怕有毒订单流（informed flow）。
  • 高频交易者：赚微观结构里的微小价差和延迟优势。速度上你不可能赢。
  • 量化基金：中频统计套利、因子投资。比的是数据、模型和成本控制。
  • 公募 / 保险 / 养老金：体量大、周期长，常常是流动性的提供者，也是「被迫交易者」。
  • 散户：情绪化、追涨杀跌、止损集中。行为套利的猎物，但也是彼此最大的对手。

如果你做日频因子策略，你的对手主要是其他量化基金和情绪化散户；如果你做日内， 对手是做市商和高频。前者比的是想法和纪律，后者比的是基础设施。 作为个人，选前者。

1.8动手：写一个极简撮合引擎

不到 80 行，你就能拥有一台真实运行的市场。这段代码值得逐行读——它会把「价格是怎么来的」 从抽象概念变成你能调试的东西。

matching_engine.py
from dataclasses import dataclass, field
from enum import Enum
from collections import deque
import itertools


class Side(Enum):
    BUY = "buy"
    SELL = "sell"


@dataclass
class Order:
    side: Side
    price: float
    qty: int
    seq: int = field(default_factory=itertools.count().__next__)
    filled: int = 0


class OrderBook:
    """价格优先、时间优先的连续撮合。"""

    def __init__(self):
        # 价格 -> 该价位的订单队列（FIFO 保证时间优先）
        self.bids: dict[float, deque] = {}
        self.asks: dict[float, deque] = {}
        self.trades: list[tuple[float, int]] = []

    def _best_bid(self):
        return max(self.bids) if self.bids else None

    def _best_ask(self):
        return min(self.asks) if self.asks else None

    def submit(self, order: Order) -> list[tuple[float, int]]:
        """提交订单，返回本次产生的成交列表 [(price, qty), ...]"""
        book = self.asks if order.side is Side.BUY else self.bids
        opposite = self._best_ask if order.side is Side.BUY else self._best_bid
        fills = []

        while order.qty > order.filled and opposite is not None:
            # 价格是否还能成交：买单要 >= 卖一，卖单要 <= 买一
            if order.side is Side.BUY and order.price < opposite:
                break
            if order.side is Side.SELL and order.price > opposite:
                break

            queue = book[opposite]
            resting = queue[0]
            deal = min(order.qty - order.filled, resting.qty - resting.filled)

            resting.filled += deal
            order.filled += deal
            fills.append((opposite, deal))
            self.trades.append((opposite, deal))

            if resting.filled == resting.qty:
                queue.popleft()
                if not queue:
                    del book[opposite]

            opposite = self._best_ask if order.side is Side.BUY else self._best_bid

        # 限价单剩余部分挂队
        if order.filled < order.qty:
            self._rest(order)
        return fills

    def _rest(self, order: Order):
        book = self.bids if order.side is Side.BUY else self.asks
        book.setdefault(order.price, deque()).append(order)

    def snapshot(self, depth: int = 3) -> dict:
        bids = sorted(self.bids.items(), key=lambda kv: -kv[0])[:depth]
        asks = sorted(self.asks.items(), key=lambda kv: kv[0])[:depth]
        return {
            "bids": [(p, sum(o.qty - o.filled for o in q)) for p, q in bids],
            "asks": [(p, sum(o.qty - o.filled for o in q)) for p, q in asks],
        }

跑一段模拟，看看大单是怎么把价格推上去的：

demo.py
ob = OrderBook()

# 挂三档卖盘
for price, qty in [(100.50, 200), (100.55, 300), (100.60, 500)]:
    ob.submit(Order(Side.SELL, price, qty))

# 一张 800 股的市价买单（价格设成极高，等价于市价）
fills = ob.submit(Order(Side.BUY, 999.0, 800))
print("fills:", fills)
print("avg  :", sum(p * q for p, q in fills) / sum(q for _, q in fills))
print("snapshot:", ob.snapshot())
fills: [(100.5, 200), (100.55, 300), (100.6, 300)] avg : 100.55625 snapshot: {'bids': [], 'asks': [(100.6, 200)]}

你看到的「最新价」是 100.50，但你实际付出的均价是 100.556，多付了 5.6 个基点。 而最后成交价变成了 100.60——市场因为你，涨了。这就是冲击成本， 它在回测里通常被一行 slippage=0 抹掉。

回测里的三个谎言

1. 用收盘价成交——收盘价是集合竞价的产物，你无法在盘中任意时刻拿到它。
2. 假设无限流动性——你的 100 万买单在盘口只有 20 万时，不可能全部按现价成交。
3. 忽略队列位置——挂在买一的限价单，前面可能有 5000 手在排队，轮不到你。

1.9本章陷阱清单

  • 把「最新成交价」当成「可成交价」。你的买入价永远是卖一，卖出价永远是买一。
  • 以为流动性是恒定的。开盘、收盘、重大新闻时，盘口会瞬间变薄几十倍。
  • 用市价单做高频调仓，然后困惑为什么收益被吃掉。
  • 在 A 股用 T+0 思路设计策略（当天买的不能当天卖）。
  • 忽略涨跌停：涨停时买不进，跌停时卖不出，回测却假设都能成交。

本章练习

  1. 用上面的引擎，模拟「连续 20 笔 100 股市价买单」和「一笔 2000 股市价买单」，比较两者的成交均价。差额就是拆单的价值。
  2. 给引擎加上「撤单」功能，然后模拟一个做市策略：同时在买一挂单、卖一挂单，看看在随机订单流下能否稳定赚到价差。
  3. 打开你常用的行情软件，找到盘口，记录某只股票开盘后 1 分钟、10 分钟、收盘前的买卖价差。差多少倍？

本章要点

  • 交易所是一台价格优先、时间优先的撮合状态机；价格是撮合的输出，不是计算的结果。
  • 盘口告诉你深度与价差，这两者共同决定了你的交易成本。
  • 价格是分段常数、事件驱动的；K 线是等间隔采样，必然损失信息。
  • 四类成本——价差、佣金税费、冲击、时机——构成策略的收益率门槛。
  • 想清楚对手是谁：日频拼想法与纪律，日内拼基础设施。
