从零造一个策略

这一章不再讲新概念，而是把前面十三章的零件装成一台机器： 一个日频横截面动量策略，从数据加载、信号构造、组合优化、回测、归因， 到成本压力测试与上线检查。你可以直接把它跑起来，然后改坏它、修好它。

我们要造的东西很简单：每个月，买入过去 12 个月涨幅靠前、但波动率不高的股票， 持有 20 个交易日，然后换仓。它不性感，也不是什么秘密，但它包含了 一个完整策略所需的全部要素——而且它大概率不会赚钱。这没关系， 你的目标是学会「如何判断它为什么不赚钱」。

14.1项目定义：先写规格，再写代码

任何策略在写代码之前，必须先回答这七个问题。答不上来，说明你还没想清楚。

问题本项目的答案
赚什么钱动量效应：赢家继续跑赢，源于反应不足与资金流
股票池沪深 300 成分股（按当时成分，避免幸存者偏差）
信号过去 12 个月收益（剔除最近 1 个月），横截面排名
过滤剔除波动率最高的 30%、ST、停牌、上市不足 1 年
持仓前 30 名，等权，单票上限 5%
调仓每月最后一个交易日生成信号，次月第一个交易日开盘执行
风控单票 5%、行业 25%、组合回撤 20% 熔断
为什么剔除最近一个月？

这是动量研究里的标准做法（12-1 momentum）。最近一个月往往存在短期反转， 把它剔除可以避免「追高买在短期顶部」。这个细节看起来小，但对策略影响很大—— 它也是「先有逻辑，再调参数」的典型例子。

14.2第一步：数据

我们需要的字段不多，但每个都必须干净：

data.py
import pandas as pd

REQUIRED = ["date", "symbol", "open", "high", "low", "close",
            "volume", "amount", "industry", "is_st", "list_date"]


def load_panel(path: str) -> pd.DataFrame:
    df = pd.read_parquet(path)
    missing = set(REQUIRED) - set(df.columns)
    if missing:
        raise ValueError(f"缺少字段: {missing}")

    df["date"] = pd.to_datetime(df["date"])
    df = df.sort_values(["symbol", "date"]).drop_duplicates(["date", "symbol"])

    # 关键：价格必须已复权（后复权），否则收益是错的
    assert df["close"].gt(0).all(), "存在非正价格"
    return df


def tradable_mask(df: pd.DataFrame, min_list_days: int = 250) -> pd.Series:
    """可交易过滤：非 ST、非停牌、上市满一年、有成交。"""
    listed_long_enough = (df["date"] - df["list_date"]).dt.days >= min_list_days
    return (~df["is_st"]) & (df["volume"] > 0) & listed_long_enough

14.3第二步：信号

signal.py
import numpy as np
import pandas as pd


def build_signal(df: pd.DataFrame, lookback: int = 252,
                 skip: int = 21, vol_cut: float = 0.70) -> pd.DataFrame:
    df = df.sort_values(["symbol", "date"]).copy()
    g = df.groupby("symbol")

    # 12-1 动量：过去 lookback 日收益，跳过最近 skip 日
    df["mom_12_1"] = g["close"].shift(skip) / g["close"].shift(lookback) - 1

    # 波动率：过去 60 日收益标准差（年化）
    df["ret_1"] = g["close"].pct_change()
    df["vol_60"] = g["ret_1"].transform(
        lambda s: s.rolling(60).std() * np.sqrt(252)
    )

    # 横截面排名（每个日期内）
    df["mom_rank"] = df.groupby("date")["mom_12_1"].rank(pct=True)
    df["vol_rank"] = df.groupby("date")["vol_60"].rank(pct=True)

    # 剔除高波动（最高的 30%）
    df["eligible"] = df["vol_rank"] <= vol_cut

    # 最终分数：动量排名，行业中性化
    df["score"] = df["mom_rank"]
    df["score"] = df.groupby(["date", "industry"])["score"].transform(
        lambda s: s.rank(pct=True)
    )
    return df
行业中性化的作用

如果不做行业中性，动量策略会系统性地超配当年最热的行业（比如 2020 年的白酒、 2023 年的 AI）。这会让策略变成「行业 bet」，而不是「选股 alpha」。 中性化之后，你在每个行业内部选最强的股票，行业暴露被大幅削弱。

14.4第三步：组合

portfolio.py
import pandas as pd


def build_target(signal: pd.DataFrame, top_n: int = 30,
                 max_weight: float = 0.05) -> pd.DataFrame:
    """每个调仓日选前 top_n 名，等权，单票上限 max_weight。"""
    rows = []
    for date, g in signal.groupby("date"):
        g = g[g["eligible"] & g["mom_12_1"].notna()]
        if len(g) < top_n * 2:
            continue
        picks = g.nlargest(top_n, "score")
        w = min(1.0 / top_n, max_weight)
        for _, row in picks.iterrows():
            rows.append({"date": date, "symbol": row["symbol"], "weight": w})
    return pd.DataFrame(rows)

注意 w = min(1/top_n, max_weight)：如果 top_n = 30，等权是 3.33%， 低于 5% 上限，所以实际上限不起作用。如果 top_n = 10，等权是 10%，就会被压到 5%， 此时总仓位只有 50%，剩下的现金是一个隐性的防御。

14.5第四步：回测

直接复用第八章的 Backtest。注意目标权重的日期必须是信号日， 引擎会在次日开盘执行。

run_backtest.py
import pandas as pd
from engine import Backtest, Costs
from metrics import summary, drawdown_series

df = load_panel("data/panel.parquet")

14.6第五步：归因——它到底在赚什么钱

attribution.py
import numpy as np
import pandas as pd
import statsmodels.api as sm


def factor_regression(strategy_ret: pd.Series, factors: pd.DataFrame) -> pd.Series:
    """把策略收益对市场/规模/价值/动量回归，看 alpha 是否显著。"""
    df = pd.concat([strategy_ret.rename("r"), factors], axis=1).dropna()
    X = sm.add_constant(df[factors.columns])
    model = sm.OLS(df["r"], X).fit(cov_type="HAC", cov_kwds={"maxlags": 5})
    out = model.params.copy()
    out["alpha_t"] = model.tvalues["const"]
    out["r2"] = model.rsquared
    return out


def yearly_returns(equity: pd.Series) -> pd.Series:
    return equity.resample("YE").last().pct_change().dropna()

典型的结果会长这样：市场 beta 0.85、动量暴露 0.3、alpha 年化 2.1%（t = 1.2）。 翻译成人话：这个策略 80% 的收益来自「持有股票」这件事本身， 动量只贡献了一点点，而且统计上不显著。

如果 alpha 的 t 值小于 2

不要急着调参数。先问：是样本太短、还是逻辑不成立、还是被成本吃掉了？ 三种情况的处理方式完全不同。样本太短 → 延长数据；逻辑不成立 → 换逻辑； 成本吃掉 → 降低换手。盲目调参只会让你离真相更远。

14.7第六步：参数敏感性

把动量窗口（6/12/24 个月）、持仓数（20/30/50）、波动率阈值（60%/70%/80%） 做成网格，跑 27 组。然后画热力图。

sensitivity.py
import itertools
import pandas as pd

grid = {
    "lookback": [126, 252, 504],
    "top_n": [20, 30, 50],
    "vol_cut": [0.6, 0.7, 0.8],
}

rows = []
for lb, n, vc in itertools.product(*grid.values()):
    sig = build_signal(df, lookback=lb, vol_cut=vc)
    tgt = build_target(sig, top_n=n)
    res = Backtest(prices, tgt.pivot(index="date", columns="symbol",
                                     values="weight").fillna(0)).run()
    s = summary(res["equity"])
    rows.append({"lookback": lb, "top_n": n, "vol_cut": vc,
                 "sharpe": s["Sharpe"], "cagr": s["CAGR"], "mdd": s["MaxDD"]})

table = pd.DataFrame(rows)
print(table.pivot_table(index=["lookback", "vol_cut"], columns="top_n",
                        values="sharpe").round(2))

你要找的不是最高值，而是一片连续的高原。如果最高夏普是 0.62， 但周围都是 0.2，那它是噪声；如果一片区域都在 0.45–0.55，说明策略对这个参数不敏感， 更可信。

14.9上线前的检查清单

  • 样本外（最近 2 年）表现是否与样本内一致？差距多大？
  • 扣除真实成本后，夏普是否仍大于 0.4？
  • 最大回撤是否在你的心理承受范围内？
  • 参数是否位于「高原」而非「孤峰」？
  • 收益归因中，alpha 的 t 值是否大于 2？
  • 策略容量是否大于你的资金量？
  • 有没有明确的退役条件？
  • 系统是否支持幂等、对账、熔断？
  • 你能否在断网、断电、券商接口故障时手动接管？
  • 如果明天开始连续亏 12 个月，你还会执行它吗？
