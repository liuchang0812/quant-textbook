Chapter 03 · 第一部 地基

收益的语言

「年化 30%」这句话几乎没有任何信息量。它可能是稳定复利，也可能是三年里两年亏、 一年翻倍。要判断一个策略的好坏，你需要一套精确的语言：简单收益与对数收益的区别、 三种年化的陷阱、夏普比率在衡量什么、最大回撤为什么比收益更值得关注。 这一章建立你的度量衡。

阅读 30 分钟 难度 中级 代码 指标库

在工程里，如果你不能用数字描述一个系统的行为，你就无法优化它。 交易也一样。但交易的麻烦在于：几乎所有直观的指标都会骗人。 收益率会被少数几笔极端交易扭曲，波动率会把上涨和下跌同等对待， 夏普比率假设收益服从正态分布——而市场最不缺的就是不服从正态分布的时刻。

所以这一章的目的不是给你一堆公式，而是让你知道每个数字在什么情况下会撒谎。

3.1简单收益与对数收益

假设一只股票从 100 涨到 120，再跌回 100。简单收益是 +20% 和 −16.67%， 算术平均 +1.67%——但你一分钱没赚。问题出在：简单收益不能相加。

对数收益（log return）解决了这个问题。定义 r = ln(P₁/P₀)， 则上涨时 r = ln(1.2) = 0.1823，下跌时 r = ln(0.8333) = −0.1823，相加正好为 0。

rlog = ln(1 + rsimple)   ⇔   rsimple = erlog − 1 (3.1)

两者的分工非常明确：

场景用哪个原因
跨期累加对数收益可加性：多期总收益 = 各期对数收益之和
跨资产加总简单收益组合收益 = 各资产收益的加权和（对数收益不成立）
统计建模对数收益更接近对称分布，方差更稳定
向人汇报简单收益「赚了 20%」比「对数收益 0.182」直观
小收益率下可以近似

当 r 很小时，ln(1+r) ≈ r − r²/2，两者几乎相等。 日收益 ±2% 以内，用哪个都行。但当你计算多年累计收益、或者处理高波动资产（比如加密货币）时， 差异会变得巨大：年化 100% 的简单收益，对应 69.3% 的对数收益。

3.2年化：三种平均，三个答案

假设一个策略四年的收益是：+50%、−20%、+30%、+10%。它的「年化收益」是多少？ 答案是：取决于你问谁。

算术平均

(0.5 − 0.2 + 0.3 + 0.1) / 4 = 17.5%

这是最乐观的答案，也是基金销售最爱用的。但它对应的是「每年都把收益取出来」的假设， 不代表你的资金实际增长。

几何平均（CAGR）

[(1.5)(0.8)(1.3)(1.1)]1/4 − 1 = 14.5% (3.2)

这才是你账户真实的年化复合增长率。它永远小于等于算术平均，差距随波动率增大。 任何严肃的策略评价都应该用 CAGR。

对数平均

exp( mean(ln(1+rt)) ) − 1 = 14.5%

与 CAGR 完全等价（数学上恒等）。它好在可以直接用日频数据计算，不必等到期末。

记住这个不等式

算术平均 ≥ 几何平均 ≥ 中位数（对右偏分布）。 当有人告诉你「平均年化 20%」，你要问的第一句话是：「算术还是几何？」 第二句是：「最大回撤多少？」

3.3波动率：风险的第一个近似

波动率就是收益率的标准差，通常按年化表示：

σ年 = σ日 × √252 (3.3)

252 是一年的交易日数（A 股约 242，美股约 252，加密资产 365）。 这个 √T 缩放来自「独立同分布」假设——它在大样本下近似成立， 但在极端行情里会失效，因为波动率本身是聚集的（volatility clustering）。

波动率不是恒定的

这是新手最容易忽略的一点：波动率会「抱团」。大波动后面跟着大波动，平静后面跟着平静。 这就是 GARCH 模型要刻画的现象。实践含义是：

  • 用过去 20 天的波动率预测明天，比用过去 3 年更准。
  • 但短窗口噪声大，所以通常用 EWMA（指数加权）折中。
  • 当波动率突然翻倍时，你的仓位应该自动减半——这就是波动率目标化。
volatility.py
import numpy as np
import pandas as pd


def ewma_vol(returns: pd.Series, halflife: int = 20) -> pd.Series:
    """指数加权波动率（日频）。halflife 越小，对近期变化越敏感。"""
    return returns.ewm(halflife=halflife, adjust=False).std() * np.sqrt(252)


def realized_vol(returns: pd.Series, window: int = 20) -> pd.Series:
    """滚动窗口已实现波动率。"""
    return returns.rolling(window).std() * np.sqrt(252)

3.4风险调整收益：谁更会「开同样的车」

两个策略，A 年化 15%、波动 10%，B 年化 25%、波动 30%。谁更好？ 如果只看收益，B 赢；但 B 的波动是 A 的三倍，你为了多赚 10 个点承担了三倍的风险。 风险调整收益指标就是用来回答这个问题的。

夏普比率

Sharpe = (Rp − Rf) / σp (3.4)

每承担一单位波动，获得多少超额收益。它是量化行业最通用的「成绩单」， 也是最被滥用的指标。它有三个致命缺陷：

  1. 它把上涨的波动也当成风险。一个只涨不跌但涨幅不均的策略，夏普会被压低。
  2. 它假设正态分布。如果策略靠卖尾部保险赚钱（平时小赚、偶尔巨亏），夏普会高得离谱，直到爆仓那天。
  3. 它可以被操纵。把流动性差的资产按模型估值而不是市价，收益序列会变得平滑，夏普虚高。这就是为什么有些基金「夏普 3」，赎回时却拿不到钱。

索提诺比率

Sortino = (Rp − Rtarget) / σ下行 (3.5)

只惩罚下行波动。对于收益分布右偏的策略（趋势跟踪、期权买方），索提诺比夏普更公平。

卡玛比率

Calmar = CAGR / |MaxDD| (3.6)

每承受 1% 的最大回撤，换来多少年化收益。这是最贴近「投资者体感」的指标—— 因为回撤是你真实会痛的东西。卡玛大于 1 已经算不错，大于 2 属于优秀。

信息比率

IR = α / σ(α) (3.7)

相对于基准的超额收益，除以超额收益的波动。它衡量的是「主动管理能力」的稳定性。 量化基金内部常用它来评价一个策略相对于其风险模型的表现。

指标衡量什么什么时候会骗你
夏普单位总波动的超额收益厚尾、平滑估值、上涨波动大的策略
索提诺单位下行波动的超额收益样本期没有大跌时，下行波动被低估
卡玛收益 / 最大回撤回撤只取了一个点，样本短时不稳定
IR超额收益的稳定性基准选择不当会扭曲结论
胜率盈利交易占比完全忽略盈亏比，单独看毫无意义

3.5回撤：唯一真正会让你出局的指标

最大回撤（Maximum Drawdown）是从历史最高点到之后最低点的跌幅：

MDD = maxt [ (peakt − trought) / peakt ] (3.8)

但最大回撤只是故事的一部分。同样重要的还有两个数字： 回撤持续了多久（underwater duration），以及多久才创新高（recovery time）。 一个 −20% 但三个月就恢复的回撤，和一个 −15% 但持续三年的回撤，对投资者的心理折磨完全不同。

关于回撤，有一个经验关系值得记住：回撤越深，回本需要的涨幅越夸张。 亏 10% 要涨 11.1%，亏 30% 要涨 42.9%，亏 50% 要涨 100%，亏 80% 要涨 400%。 这就是为什么风险管理的首要目标不是「多赚」，而是「别亏大」。

回撤的心理阈值

研究表明，大多数投资者在回撤 20%–25% 时开始出现非理性行为（赎回、砍仓、加杠杆赌回来）。 这意味着：如果你的策略历史最大回撤是 30%，你大概率拿不住它。 选择策略时，要选「回撤在你心理承受范围内」的那个，而不是收益最高的那个。

3.6分布的形状：偏度与峰度

正态分布由均值 and 方差两个参数完全决定。但真实收益分布有第三个和第四个特征：

  • 偏度（skewness）：分布不对称的程度。负偏 = 左尾长 = 偶尔巨亏。卖期权、做空波动率的策略都是负偏。
  • 峰度（kurtosis）：尾部的厚度。超额峰度 > 0 表示极端值比正态分布更频繁。股票日收益的超额峰度通常在 3–10 之间。

这两个数字之所以重要，是因为它们决定了「平均」是否可信。 一个负偏、高峰度的策略，可能连续 300 天每天赚 0.05%，然后在第 301 天亏掉 40%。 它的夏普比率会非常漂亮，因为夏普完全看不见那个 −40%。

一个判断练习

看到一条几乎笔直向上的资金曲线，先别羡慕。问三个问题： ① 它的收益是不是集中在少数几天？② 它有没有在极端行情里交易过？③ 它的估值是市价还是模型价？ 三个问题里有一个答不上来，这条曲线就不可信。

3.7相关性：分散的数学

两个资产的组合波动率不是各自波动率的平均，而是：

σp² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂ (3.9)

当 ρ = 1，波动率线性相加，分散无效；当 ρ = 0，波动率按平方和开根号， 两个同波动率的资产各占一半，组合波动率降到原来的 70.7%；当 ρ = −1，理论上可以完全消除波动。

但这里有一个残酷的现实：相关性在危机时会趋近于 1。 平时不相关的资产，在流动性危机里会一起被抛售，因为它们变成了同一个东西——「需要卖掉的资产」。 2008 年、2020 年 3 月、2022 年，都上演过这一幕。

实践含义

用长期平均相关性做风险模型，会系统性低估尾部风险。 稳健的做法是：同时看「正常时期相关性」和「压力时期相关性」， 并在仓位设计里假设后者才是真的。这也是第九章压力测试的起点。

3.9动手：一个够用的指标库

这段代码值得存下来，后面每一章都会用到。它刻意写得很直白，方便你改。

metrics.py
import numpy as np
import pandas as pd


def to_returns(equity: pd.Series) -> pd.Series:
    return equity.pct_change().dropna()


def cagr(equity: pd.Series, periods_per_year: int = 252) -> float:
    """复合年化增长率。用首尾净值计算，不受中间波动干扰。"""
    n = len(equity) / periods_per_year
    if n <= 0 or equity.iloc[0] <= 0:
        return np.nan
    return (equity.iloc[-1] / equity.iloc[0]) ** (1 / n) - 1


def ann_vol(returns: pd.Series, periods_per_year: int = 252) -> float:
    return returns.std() * np.sqrt(periods_per_year)


def sharpe(returns: pd.Series, rf: float = 0.0, periods_per_year: int = 252) -> float:
    excess = returns - rf / periods_per_year
    sd = excess.std()
    return np.nan if sd == 0 else excess.mean() / sd * np.sqrt(periods_per_year)


def sortino(returns: pd.Series, rf: float = 0.0, periods_per_year: int = 252) -> float:
    excess = returns - rf / periods_per_year
    downside = excess[excess < 0].std()
    return np.nan if downside == 0 else excess.mean() / downside * np.sqrt(periods_per_year)


def drawdown_series(equity: pd.Series) -> pd.Series:
    """水下曲线：当前净值相对历史最高点的跌幅（负数）。"""
    peak = equity.cummax()
    return equity / peak - 1


def max_drawdown(equity: pd.Series) -> float:
    return drawdown_series(equity).min()


def drawdown_stats(equity: pd.Series) -> dict:
    """最大回撤 + 最长水下时间（交易日）。"""
    dd = drawdown_series(equity)
    mdd = dd.min()
    trough = dd.idxmin()
    peak = equity.loc[:trough].idxmax()
    recovery = equity.loc[trough:][equity.loc[trough:] >= equity.loc[peak]]

    longest, current = 0, 0
    for v in dd:
        current = current + 1 if v < 0 else 0
        longest = max(longest, current)

    return {
        "max_drawdown": mdd,
        "peak": peak,
        "trough": trough,
        "recovery": recovery.index[0] if len(recovery) else None,
        "underwater_days": longest,
    }


def summary(equity: pd.Series) -> pd.Series:
    r = to_returns(equity)
    dd = drawdown_stats(equity)
    return pd.Series({
        "CAGR": cagr(equity),
        "Vol": ann_vol(r),
        "Sharpe": sharpe(r),
        "Sortino": sortino(r),
        "MaxDD": dd["max_drawdown"],
        "Calmar": cagr(equity) / abs(dd["max_drawdown"]) if dd["max_drawdown"] else np.nan,
        "UnderwaterDays": dd["underwater_days"],
    })

一个实现细节

drawdown_stats 里查找 recovery 的写法用了布尔索引，在长序列上会慢。 生产环境建议用 np.argmax 找到第一个 True 的位置，或者直接用累计最大值做向量化。 这类「能跑但不够快」的代码，在回测里会被调用几十万次，值得优化。

3.10本章陷阱清单

  • 用算术平均汇报收益，把 17.5% 说成「年化」。
  • 只看夏普，不看偏度和回撤。
  • 用日波动率 × √252 去估计包含极端行情的年度风险。
  • 把「最大回撤」当成「未来最大回撤」。历史极值只是下限，不是上限。
  • 在样本期没有危机的情况下，相信「低相关性」能保护你。
  • 忽略回撤持续时间——它比深度更能摧毁投资者的执行力。

本章要点

  • 对数收益可加，简单收益可加权；跨期用对数，跨资产用简单。
  • 算术平均 ≥ 几何平均；只有 CAGR 代表你账户的真实增长。
  • 波动率聚集，必须用 EWMA 或 GARCH 类方法动态估计。
  • 夏普有三大缺陷：惩罚上涨、假设正态、可被平滑估值操纵。
  • 回撤的深度、持续时间、恢复时间，共同决定你能否拿住一个策略。
  • 相关性在危机时趋近 1，分散化没有你想象的那么可靠。
