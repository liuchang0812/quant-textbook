金融市场是一台专门生产「假规律」的机器。随机波动会长得像趋势， 噪声会长得像信号，而你恰好会在看到它的那一刻相信它。 这一章给你三件武器：样本量的直觉、假设检验的正确用法、以及对付多重检验的纪律。

先做一个思想实验。让 1000 个人各自抛 10 次硬币，总会有几个人连续抛出 10 个正面。 如果你只采访这几个人，你会得出「有人天生擅长抛正面」的结论，还会想拜他为师。 金融市场每天都在生产这样的人——他们叫「去年的冠军基金」。

统计学的全部意义，就是让你在这种情况下保持清醒。它不告诉你「什么是对的」， 它告诉你「这个结果有多可能只是运气」。

5.1大数定律，和小数定律

大数定律说：样本量足够大时，样本均值会收敛到真实期望。 它的潜台词是：「足够大」比你想的大得多。

假设一个策略真实胜率 52%，你想通过观察来确认它大于 50%。需要多少笔交易？ 用标准误公式 SE = √(p(1−p)/n)，要让 2% 的优势达到 2 倍标准误：

n ≈ p(1−p) / (0.01)² ≈ 0.25 / 0.0001 = 2,500 笔 (5.1)

2500 笔。如果你的策略每天交易一次，需要十年。这就是为什么「三个月实盘验证」毫无意义—— 它连噪声都还没走完一个周期。

更麻烦的是，人对随机性的直觉是反的。我们会在 20 次里看到 14 次盈利，就认为「找到了规律」， 这叫小数定律：错误地认为小样本也应该反映总体特征。 赌徒谬误、热手效应、以及大部分技术指标的诞生，都源于这个错误。

一个粗糙但好用的估算

评价一个日频策略，至少需要 3–5 年的日频数据（约 750–1250 个观测）， 才能让夏普比率的标准误降到可接受的范围。少于这个量，你看到的差异大部分是噪声。 公式：SE(Sharpe) ≈ √((1 + SR²/2) / T)，T 为年数。

5.2假设检验：p 值到底在说什么

假设检验的逻辑是反证法：先假设「没有效果」（原假设 H₀），然后看观测到的数据 在这个假设下有多不可能。如果太不可能，就拒绝 H₀。

t = (x̄ − μ₀) / (s / √n) (5.2)

p 值的定义是：在原假设为真的前提下，观测到当前结果或更极端结果的概率。 注意它不是「原假设为真的概率」，也不是「策略有效的概率」。 这个区别被误解了一百年，包括很多博士。

p < 0.05 不意味着什么

它不意味着策略有效，不意味着可复现，不意味着经济意义显著。 它只意味着：如果真实收益是 0，你观测到这么高收益的概率小于 5%。 而在你试了 100 个策略之后，出现至少一个 p < 0.05 的概率是 99.4%。

5.3多重检验：量化研究最大的陷阱

这是本章最重要的一节。假设你完全不懂交易，只是随机生成 1000 个策略， 每个策略都在同一段历史上回测。因为随机性，其中必然有一些看起来非常棒。 如果你挑出最好的那个，你会得到一条年化 30%、夏普 2 的曲线——而它背后的真实 alpha 是零。

有三种应对方法，从松到严：

方法做法代价
Bonferroni把显著性阈值除以试验次数：α/N过于保守，会漏掉真实信号
FDR 控制控制「假阳性占所有阳性」的比例需要更多假设，解释复杂
Deflated Sharpe根据试验次数、样本长度、收益偏度峰度，调整夏普的显著性需要记录你试过多少次（很多人不愿记）
最重要的纪律

记录你试过的每一个策略。不是记录成功的，是记录所有的。 一个研究日志，包含日期、假设、参数、样本内外结果。 当你发现「我试了 47 个变体」时，你对第 48 个的夏普 1.8 就不会那么兴奋了。

5.4Bootstrap：不假设分布的置信区间

传统 t 检验假设收益服从正态分布。但我们已经知道它有厚尾。 Bootstrap 提供了一种不依赖分布假设的方法：有放回地重采样。

做法极其简单：从你的 N 个日收益里，随机抽 N 个（允许重复），算一次夏普； 重复 1000 次，得到夏普的分布；取 2.5% 和 97.5% 分位数，就是 95% 置信区间。

bootstrap.py
import numpy as np

def bootstrap_ci(x, stat, n_boot=2000, alpha=0.05, seed=0):
    """对任意统计量做 bootstrap 置信区间。"""
    rng = np.random.default_rng(seed)
    x = np.asarray(x)
    n = len(x)
    stats = np.empty(n_boot)
    for i in range(n_boot):
        idx = rng.integers(0, n, n)
        stats[i] = stat(x[idx])
    lo, hi = np.quantile(stats, [alpha / 2, 1 - alpha / 2])
    return stat(x), lo, hi


def sharpe(x):
    sd = x.std(ddof=1)
    return np.nan if sd == 0 else x.mean() / sd * np.sqrt(252)


# 用法
# point, lo, hi = bootstrap_ci(returns.values, sharpe)
# print(f"Sharpe {point:.2f}  95% CI [{lo:.2f}, {hi:.2f}]")

如果你的置信区间是 [−0.3, 2.1]，那么「策略有效」这个结论 就非常脆弱——它和「没有效果」在统计上无法区分。很多研究报告只给点估计， 不给区间，这等于隐藏了不确定性。

Block Bootstrap

普通 bootstrap 假设每个观测独立。但收益有自相关（波动聚集、动量）， 独立重采样会破坏这个结构，低估不确定性。解决办法是按块重采样： 每次抽取连续的一段（比如 20 天），而不是单日。

block_bootstrap.py
def block_bootstrap_ci(x, stat, block=20, n_boot=2000, alpha=0.05, seed=0):
    rng = np.random.default_rng(seed)
    x = np.asarray(x)
    n = len(x)
    n_blocks = int(np.ceil(n / block))
    out = np.empty(n_boot)
    for i in range(n_boot):
        starts = rng.integers(0, n - block, n_blocks)
        sample = np.concatenate([x[s:s + block] for s in starts])[:n]
        out[i] = stat(sample)
    return stat(x), *np.quantile(out, [alpha / 2, 1 - alpha / 2])

5.5置换检验：最诚实的「这会不会是运气」

如果你想知道「我的择时能力是真的，还是运气」，最直接的办法是： 把信号和收益的对应关系随机打乱，看会发生什么。

具体做法：保持收益序列不变，随机重排信号（或日期），重跑策略 1000 次， 得到「无预测能力」情况下的收益分布。如果你的真实收益落在这个分布的 99% 分位之外， 才有资格说「这可能不是运气」。

permutation.py
import numpy as np

def permutation_test(signal, forward_ret, n_perm=2000, seed=0):
    """检验信号与未来收益的关系是否显著。
    signal: 每日信号（-1 ~ 1）
    forward_ret: 次日收益
    """
    rng = np.random.default_rng(seed)
    signal = np.asarray(signal)
    forward_ret = np.asarray(forward_ret)

    real = np.corrcoef(signal, forward_ret)[0, 1]
    null = np.empty(n_perm)
    for i in range(n_perm):
        null[i] = np.corrcoef(rng.permutation(signal), forward_ret)[0, 1]

    p = (np.sum(np.abs(null) >= abs(real)) + 1) / (n_perm + 1)
    return real, p, null

这个检验的妙处在于：它不假设任何分布，直接回答「在完全没有预测能力的世界里， 我看到的这个相关性有多常见」。它比 t 检验更稳健，也更难被自欺欺人。

5.6平稳性：金融时间序列的麻烦

大部分统计方法都假设数据是平稳的：均值和方差不随时间变化。 但价格显然不平稳（长期上涨），波动率也不平稳（聚集），连相关性都不平稳（危机时一起跌）。

实践中的处理方式：

  • 用收益率，不用价格。收益率比价格更接近平稳。
  • 用滚动窗口或扩展窗口。承认参数会变，定期重估。
  • 做差分。如果序列有单位根，差分后再建模。
  • 不要外推太远。任何模型的预测能力都随时间衰减。
一个实用检验

ADF 检验（Augmented Dickey-Fuller）用来判断序列是否有单位根。 在 Python 里用 statsmodels.tsa.stattools.adfuller。 但要注意：通过了 ADF 检验不等于平稳，只说明「没有单位根」。 结构突变（比如 2020 年 3 月）会让所有历史检验失效。

5.7回归：几何直觉与 R² 的欺骗性

线性回归在几何上就是把 y 投影到 X 张成的空间上。 残差是投影的垂线，所以残差和 X 正交。这个视角比公式更有用： 它告诉你 OLS 找到的是「在 X 能解释的方向上，最接近 y 的那个点」。

β̂ = (XᵀX)−1Xᵀy     R² = 1 − SSres/SStot (5.3)

R² 表示「y 的方差中被 X 解释的比例」。它在量化里经常被误读：

  • R² = 0.02 在预测股票收益时可能已经很有价值（因为信噪比极低）。
  • R² 高不代表因果，也不代表能赚钱（可能只是同期相关）。
  • 加入更多变量，R² 一定上升，哪怕变量是噪声。所以要看调整 R² 或样本外 R²。
伪回归

两个都有趋势的时间序列做回归，会得到极高的 R² 和显著的 t 值， 但两者可能毫无关系（比如「中国 GDP」和「美国人口」）。 这叫伪回归（spurious regression）。解决办法：差分、加协整检验、或者用收益率而非价格。

5.8本章陷阱清单

  • 用 3 个月的数据判断策略有效。
  • 把 p < 0.05 当成「策略有效」。
  • 试了 50 个变体，只报告最好的那个。
  • 用普通 bootstrap 处理有自相关的收益序列。
  • 对价格做回归而不做差分。
  • 用 R² 高低判断因子好坏。
  • 忽略样本外检验，或者样本外只留了最后 10%。

本章练习

  1. 用 bootstrap_ci 计算一个真实策略夏普的 95% 置信区间。它跨过 0 了吗？
  2. 生成 500 个纯随机策略（零 alpha），记录最大夏普。改变回测年数，观察最大夏普如何变化，验证 √(2 ln N / T) 这个近似。
  3. 对一个你相信的因子做置换检验，看 p 值是多少。
  4. 构造两个有趋势但无关的序列，做回归，观察 R² 有多高。然后差分后再回归。

本章要点

  • 确认 2% 的胜率优势需要约 2500 笔交易；短期实盘验证没有统计意义。
  • p 值是「H₀ 为真时观测到该结果的概率」，不是「策略有效的概率」。
  • 多重检验必然产生假冠军；记录试验次数，使用 Deflated Sharpe 或 FDR。
  • Bootstrap 给出不依赖分布假设的置信区间；有自相关时用 Block Bootstrap。
  • 置换检验直接回答「这会不会是运气」，是最诚实的检验之一。
  • 金融序列不平稳；用收益率、滚动窗口、差分来逼近平稳。
