Chapter 09 · 第三部 工程

组合构建
与风险管理

单个策略决定你能不能赚钱，组合决定你能不能睡得着。 马科维茨给了我们优美的数学，但它在实战中经常变成「误差放大器」。 这一章讲清楚：分散到底怎么起作用、为什么风险平价更稳健、 以及如何用波动率目标化把一条颠簸的曲线变平滑。

假设你有两个策略，各自的年化收益都是 10%，波动都是 20%，相关性为 0。 各投一半，组合收益还是 10%，但波动降到 14.1%。你什么都没做，夏普从 0.5 变成了 0.71。 这就是分散的魔力——它是金融里唯一「免费的午餐」。

但这顿午餐有条件：相关性必须真的低，而且必须在你需要它低的时候也低。 而市场最擅长的，就是在你最需要分散的时候，让所有东西一起跌。

9.1分散的数学：为什么 1+1 < 2

对于 N 个等权、同波动率 σ、两两相关性 ρ 的资产，组合波动率是：

σp = σ · √( 1/N + (1 − 1/N)·ρ ) (9.1)

当 N → ∞，σp → σ√ρ。这就是「不可分散的风险」。 如果 ρ = 0.5，你最多只能把波动降到原来的 70.7%，再怎么加资产都没用。

9.2马科维茨：优美的理论，糟糕的实践

均值-方差优化要解决的问题是：在给定风险下最大化收益。数学上很干净：

maxw   wᵀμ − (λ/2)·wᵀΣw    s.t.   Σwi = 1 (9.2)

解出来是 w* ∝ Σ⁻¹μ。漂亮，但实战中经常灾难性失败。 原因只有一个：它把估计误差当成了真实信号。

误差最大化器

Michaud 把均值-方差优化称为「误差最大化器」（error maximizer）。 原因：优化器会超配那些被高估收益、低估风险的资产， 而估计误差恰好让某些资产看起来「高收益低风险」。结果你买到的是噪声，不是 alpha。

三个补救办法

  1. 不要优化 μ。用等权、风险平价、或简单的打分权重，只优化风险。
  2. 收缩协方差矩阵。Ledoit-Wolf 收缩把样本协方差向结构化矩阵拉，降低估计误差。
  3. 加约束。单资产上限、行业中性、换手约束。约束越强，优化器越难「发挥想象力」。

9.3风险平价：不预测收益的配置

风险平价（Risk Parity）的核心思想是：不猜收益，只分配风险。 每个资产对组合总风险的贡献相等。这样你不需要估计 μ，只需要估计 Σ——而 Σ 的估计误差小得多。

风险贡献的定义是：

RCi = wi · (Σw)i / √(wᵀΣw) (9.3)

目标是让所有 RCi 相等。这个问题没有解析解，但可以用迭代法快速求解：

risk_parity.py
import numpy as np


def risk_contributions(w: np.ndarray, cov: np.ndarray) -> np.ndarray:
    port_var = w @ cov @ w
    marginal = cov @ w
    return w * marginal / np.sqrt(port_var)


def erc_weights(cov: np.ndarray, iters: int = 500, tol: float = 1e-10) -> np.ndarray:
    """等风险贡献（Equal Risk Contribution）权重，用循环坐标下降求解。"""
    n = cov.shape[0]
    w = np.ones(n) / n
    for _ in range(iters):
        prev = w.copy()
        for i in range(n):
            # 目标：RC_i = σ / n，即 w_i·(Σw)_i = σ² / n
            target = (w @ cov @ w) / n
            a = cov[i, i]
            b = (cov[i] @ w) - cov[i, i] * w[i]
            # 解 a·w_i² + b·w_i − target = 0，取正根
            disc = b * b + 4 * a * target
            w[i] = (-b + np.sqrt(max(disc, 0))) / (2 * a)
        w = np.clip(w, 0, None)
        w /= w.sum()
        if np.max(np.abs(w - prev)) < tol:
            break
    return w


def portfolio_vol(w: np.ndarray, cov: np.ndarray) -> float:
    return float(np.sqrt(w @ cov @ w))
风险平价的隐含杠杆

债券波动低，股票波动高。要让两者风险贡献相等，债券的权重会非常大（可能 80%）。 为了让整体收益可接受，通常会对整个组合加杠杆。这就是「风险平价基金」的典型结构。 对个人来说，不加杠杆的风险平价依然有意义：它会让你的组合更稳， 只是收益也会更低。

9.4波动率目标化：让曲线变平滑

这是实战中最有用的技术之一，原理简单到一句话： 波动高的时候减仓，波动低的时候加仓，让组合的波动率保持恒定。

wt = min( Lmax , σtarget / σ̂t ) (9.4)

假设目标波动 10%，当前估计波动 20%，则仓位系数 = 0.5。 如果波动降到 8%，系数 = 1.25（但受最大杠杆限制）。

vol_target.py
import numpy as np
import pandas as pd


def vol_target_returns(returns: pd.Series, target: float = 0.10,
                       halflife: int = 20, max_leverage: float = 2.0,
                       periods: int = 252) -> pd.Series:
    """对单策略做波动率目标化。returns 为日频策略收益。"""
    vol = returns.ewm(halflife=halflife, adjust=False).std() * np.sqrt(periods)
    scale = (target / vol).clip(upper=max_leverage)
    scale = scale.shift(1)          # 用昨天的波动决定今天的仓位，避免前视
    return returns * scale


def compare(returns: pd.Series):
    raw = returns.dropna()
    vt = vol_target_returns(returns).dropna()
    out = pd.DataFrame({
        "raw": [raw.mean() * 252, raw.std() * np.sqrt(252),
                raw.mean() / raw.std() * np.sqrt(252)],
        "vol_target": [vt.mean() * 252, vt.std() * np.sqrt(252),
                       vt.mean() / vt.std() * np.sqrt(252)],
    }, index=["ann_ret", "ann_vol", "sharpe"])
    return out

波动率目标化的效果通常是：收益略降，波动大幅降，夏普上升，最大回撤显著改善。 它不创造 alpha，但它让同样的 alpha 变得更容易持有。

一个副作用

波动率目标化在危机初期会自动减仓，这很好；但当波动率突然飙升又迅速回落时， 它会在低点减仓、高点加仓，产生「波动率陷阱」损耗。 解决办法：对波动率估计做平滑，或者设置调仓阈值（变化超过 20% 才调整）。

9.5风险度量：VaR、CVaR 与压力测试

VaR：在 95% 置信度下，我最多亏多少？

VaRα = −Quantile1−α(R) (9.5)

VaR 的问题是：它只告诉你「阈值在哪」，不告诉你「超过阈值会有多惨」。 而且它不满足次可加性——两个 VaR 为 100 的组合，合并后 VaR 可能大于 200。

CVaR：超过阈值后的平均损失

CVaRα = −E[ R | R < −VaRα ] (9.6)

CVaR（也叫 Expected Shortfall）衡量尾部损失的期望值，是更稳健的风险度量。 监管机构（巴塞尔协议）已经从 VaR 转向 CVaR。

压力测试：不看历史，看假设

VaR 和 CVaR 都基于历史分布，而历史不会重复。压力测试问的是： 如果发生 X，我会怎样？

  • 历史情景：2008 金融危机、2015 股灾、2020 年 3 月、2022 年加息。
  • 假设情景：股指单日 −10%、利率 +200bps、相关性全部升到 0.9。
  • 反向压力测试：什么情况下我会亏掉 50%？（然后问这个情况有多可能）
相关性假设是压力测试的核心

大多数风险模型在正常时期表现良好，在危机时期集体失效，因为它们假设相关性稳定。 压力测试时，应该手动把相关性调高（比如全部设为 0.8）， 再看组合的损失。这比任何 VaR 模型都更接近真相。

9.6尾部与凸性：为最坏的情况付费

如果你的策略是负偏的（卖期权、carry、杠杆套利），你需要一些「凸性」来对冲尾部。 常见做法：

  • 买入虚值看跌期权：成本是持续的保费，收益是危机时的爆发。
  • 持有少量趋势策略：趋势策略在危机中往往正收益（因为跌势持续）。
  • 保留现金：最朴素的凸性，代价是机会成本。

这类对冲在 90% 的时间里都在亏钱，只有在 10% 的时间里救命。 它的心理难度极高——你会在连续亏损 18 个月后想放弃它，而那往往是它最该被保留的时候。

9.7本章陷阱清单

  • 用样本协方差直接做均值-方差优化。
  • 以为「持有 50 只股票」就是分散。
  • 用长期平均相关性做风险模型，忽略危机时的相关性上升。
  • 波动率目标化时用了当天的波动率（前视）。
  • 把 VaR 当成「最大可能损失」。
  • 压力测试只跑历史情景，不做假设情景。
  • 在负偏策略上不加尾部对冲，还加杠杆。

本章练习

  1. 用 erc_weights 对 5 个资产（股票、债券、黄金、商品、现金）求权重，与等权对比波动率。
  2. 对一个策略做波动率目标化，比较原始与目标化后的夏普、最大回撤、以及年化换手。
  3. 计算你组合的 VaR 和 CVaR（95%），然后手动把所有相关性设为 0.8，重算一次。
  4. 设计一个反向压力测试：什么情景会让你的组合亏 40%？这个情景的概率有多大？

本章要点

  • 分散的极限由相关性决定，不由资产数量决定。
  • 均值-方差优化是误差放大器；实战应避免优化 μ，多用风险平价或简单权重。
  • 风险平价只依赖协方差，估计误差更小，是更稳健的配置方法。
  • 波动率目标化不创造 alpha，但能让 alpha 更容易被持有。
  • VaR 不描述尾部，CVaR 更稳健；压力测试必须包含相关性上升的情景。
  • 负偏策略需要凸性对冲，而凸性对冲在大多数时候都在亏钱。
