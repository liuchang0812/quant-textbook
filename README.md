## 这本书想解决什么问题

市面上大多数交易书，要么教你画线，要么堆满公式却不告诉你钱从哪里来。这本书走第三条路：

**把市场当成一个有摩擦、有对手、有信息不对称的工程系统**，用程序员熟悉的方式——定义、拆解、测量、迭代——把它讲清楚。

你会学到：

- 期望值如何决定生死，以及为什么「胜率 60%」可能是必输的策略
- 回测如何欺骗你（十种具体的作弊方式，以及如何逐个堵住）
- 因子如何从噪声里被提取，以及为什么 600 个随机策略里总有一个「夏普 1.5」
- 一套真实的系统在凌晨三点崩掉时，你该看哪个日志

## 五个可交互实验

不是截图，是手写 canvas，参数可拖动、结果实时重算：

1. **期望值计算器** — 改胜率与盈亏比，看期望如何翻转
2. **凯利蒙特卡洛** — 150 条资金曲线同时重绘，亲眼看到仓位过大如何毁灭账户
3. **风险指标实验室** — 夏普、索提诺、最大回撤、Calmar 的差异
4. **多重检验** — 600 个纯随机策略，如何产出「夏普 1.5 的冠军」
5. **Almgren-Chriss 最优执行** — 冲击成本与时机风险的权衡

## 修改与构建

`index.html` 是由 `src/` 下的分章片段拼接生成的，不要直接改它。

```bash
python3 build.py         # src/*.html → index.html
```

片段按文件名排序拼接：

- `00-head.html` — `<head>`、全部 CSS、侧栏骨架
- `01`–`16` — 各章正文
- `99-foot.html` — 页脚、全部 JS（含 5 个实验的引擎）

## 技术选择

| 决定 | 原因 |
|---|---|
| 单文件、零 CDN | 断网、拷 U 盘、发邮件都能打开；十年后还能打开 |
| 公式用 HTML/CSS 而非 KaTeX | 省 300KB，且不依赖外部字体 |
| 图表手写 SVG | 可被打印、可被缩放、可被 grep |
| 交互手写 canvas | 无框架依赖，源码可读 |

## 说明

- 书中的回测输出（夏普、成本压力测试等数字）是**示意值**，用于教你怎么读结果，不是可复现的收益。
